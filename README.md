# محرر مستندات المكتب القانوني

صفحة واحدة (`index.html`) تعمل في المتصفح بلا خادم، وتصلح للرفع على GitHub Pages.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً وارفع إليه `index.html` ومجلد `library`.
2. من Settings ثم Pages اختر الفرع `main` والمجلد الجذر، واحفظ.
3. سيظهر الرابط بالشكل `https://اسمك.github.io/اسم-المستودع/`.

## المكتبة القانونية (سحابية)
- لا تتضمن الأداة أي نصوص قانونية جاهزة، لأن النص يجب أن يؤخذ حرفياً من مصدر رسمي. ضع النصوص التي تعتمدها (الدستور، القوانين، اللوائح، الأحكام) كملفات `.txt` داخل `library/`.
- سجّل كل ملف في `library/index.json` هكذا:
```json
{"items":[{"title":"القانون المدني","kind":"قانون","file":"civil.txt"}]}
```
- كل من يفتح الرابط يحصل على المكتبة نفسها بعد كل تحديث (commit). ويمكن لكل مستخدم إضافة نصوص خاصة من تبويب «المكتبة» وتُحفظ على جهازه فقط.

## الشات
يعمل بمفتاح Anthropic API يدخله كل مستخدم في تبويب «الإعدادات». يُحفظ المفتاح في متصفحه فقط ويُرسل مباشرة إلى Anthropic. لا تكتب مفتاحاً داخل الكود أبداً.

## حدود يجب معرفتها
- يدعم ملفات `.docx` (Word 2007 وما بعده). ملفات `.doc` القديمة تُحفظ أولاً بصيغة docx من Word.
- اختيار مجلد للحفظ يعمل في Chrome وEdge على الكمبيوتر. في أندرويد يُنزَّل الملف في مجلد التنزيلات.
- راجع دائماً كل نص قانوني مُدرج قبل الاعتماد، فالنموذج قد يخطئ.
